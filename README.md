## 🌟 Ключевые Возможности

### 📸 1. ИИ-Распознавание Скриншотов Матчей (AI Vision OCR)
- **Мгновенный ввод результатов:** Игроку достаточно прикрепить скриншот послематчевой статистики из EA FC / FIFA.
- **Умное распознавание зеркальных таблиц:** Учитывает специфику интерфейса игры — считывает голы и ассисты с разделением по левой и правой сторонам экрана.
- **Индивидуальная статистика:** Автоматически заносит забитые мячи и голевые передачи конкретных футболистов в базу данных лиги.

### 🤖 2. Виртуальный ИИ-Аналитик и Собеседник «Темшик»
- **Интерактивное общение:** Активируется в ЛС и общих чатах по кодовому слову `темшик` (например: *"Темшик, какие шансы у команды на топ-3?"*).
- **Математический расчёт шансов:** Анализирует набранные очки, оставшиеся туры, разницу голов и текущую форму (`W-D-L`), выдавая аналитические вероятности в процентах.
- **Память и регламент:** Знает историю прошлых сезонов, правила турнира и регламент киберспортивной лиги.

### 🏆 3. Автоматизированная Турнирная Система (Лига и Кубок)
- **Динамическая таблица:** Мгновенный пересчет очков, побед, ничьих, поражений, забитых и пропущенных мячей.
- **Кубковые турниры:** Поддержка кубковой сетки, раундов плей-офф и генерация визуальной сетки матчей.
- **Двухэтапная верификация:** Подтверждение результатов соперником в ЛС с защитой от застревания и системой споров.

### 🎨 4. Визуальные Карточки и Инфографика
- **Карточки игроков:** Генерация индивидуальных карточек игроков с детальной статистикой матчей, голов, ассистов и рейтингом.
- **Топ-бомбардиры и ассистенты:** Создание красивых графических отчетов (изображений) по лучшим бомбардирам и ассистентам лиги и кубка.

### ⚙️ 5. Расширенная Панель Администратора
- Управление турами, дедлайнами, пакетное открытие раундов и автоматические напоминания.
- Технические поражения (ТП), дисквалификации, ручная корректировка счетов и диспутов.
- Импорт участников и редактирование составов клубов.

## 🚀 Быстрый Запуск

### 1. Клонирование и Установка Зависимостей

```bash
git clone https://github.com/Test996817/logovobot.git
cd logovobot

# Создание и активация виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

### 2. Настройка Переменных Окружения (`.env`)

Создайте файл `.env` в корневой директории:

```env
TELEGRAM_BOT_TOKEN=7777777777:AAA_your_telegram_bot_token
ADMIN_IDS=123456789,987654321
LEAGUE_SQLITE_PATH=league.db

# Ключ Gemini API для распознавания скриншотов
GEMINI_API_KEY=AIzaSy_your_primary_gemini_key

# Второй ключ Gemini API для свободной беседы (изоляция лимитов)
GEMINI_CHAT_API_KEY=AIzaSy_your_secondary_gemini_key
```

### 3. Локальный Запуск

```bash
python main.py
```

## 🐧 Деплоймент на Сервер (Systemd Linux Service)

Для бесперебойной работы бота на VPS создайте `systemd` сервис:

```bash
sudo nano /etc/systemd/system/logovobot.service
```

Вставьте следующую конфигурацию:

```ini
[Unit]
Description=LogovoBot Telegram Bot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/logovobot
ExecStart=/root/logovobot/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Перезапустите менеджер сервисов и активируйте автозапуск:

```bash
sudo systemctl daemon-reload
sudo systemctl enable logovobot
sudo systemctl start logovobot
```

Просмотр логов в реальном времени:
```bash
journalctl -u logovobot -f
```

## 💬 Команды Бот-Системы

### 👤 Команды Игрока
- `/start` — Запуск бота, регистрация профиля и выбор клуба.
- `👤 Мой кабинет` — Панель управления игрока, список матчей, загрузка состава и отправка результатов.
- `📊 Таблица лиги` — Актуальная турнирная таблица, гонка бомбардиров и ассистентов с графическим отчетом.
- `🏆 Турниры` — Меню лиги и кубковых противостояний.
- `темшик [ваш вопрос]` — Общение с ИИ-аналитиком (расчет шансов, правила, история лиги).

### ⚙️ Команды Администратора
- `⚙️ Админ-панель` — Открытие административной панели управления.
- Управление турами, дедлайнами, пакетное открытие раундов.
- Управление кубковой сеткой и матчами плей-офф.
- Назначение технических поражений (ТП), разрешение споров и ручная корректировка результатов.
- Управление игроками, импорт составов и редактирование клубов.
